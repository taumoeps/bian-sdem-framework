# SDEM — Controls register

> Generated by `python -m sdem.controls` from `metamodel/controls.json`; CI fails if it is stale.

A **control** is an automatic check that enforces a rule of the rulebook (the metamodel). This register says, for each one, what it enforces, where it is built, when it runs, **where its outcome is recorded**, and **what monitors it**.

**Monitoring today:** Continuous integration only: every push and pull request runs all controls on the example data. There is no production monitoring, alerting or dashboard yet — that arrives with ingestion of real data (ROADMAP).
