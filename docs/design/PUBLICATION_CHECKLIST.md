# Publication checklist

> **A record, in its original words.** It uses SDEM's old names (SDMM, *mapping set*, *export*, `sdmm-*` …) — what each means today: [`renamed-from-sdmm.md`](../history/renamed-from-sdmm.md).

- [ ] Confirm independent ownership and review employment agreement, IP-assignment, confidentiality and conflict-of-interest obligations with qualified counsel.
- [ ] Ensure no employer/client source diagrams, names, code, metadata or confidential patterns are present.
- [ ] Confirm BIAN trademark, reference-content, redistribution and attribution permissions.
- [ ] Verify third-party model and ArchiMate exchange format licensing before distributing copied assets.
- [ ] Publish official maintainers/contact and complete conduct reporting process.
- [ ] Decide contribution terms and security disclosure channel.
- [ ] Review all statements implying compliance, accuracy or endorsement.
- [ ] Add an initial release tag and changelog.

Personal equipment and Git commit timestamps **do not establish exclusive IP ownership**.
