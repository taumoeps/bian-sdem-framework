# Made-up design exports — for practising design onboarding

`confluence-folder-export/` is a **made-up** Confluence export of a payments design ("Payments Hub Design") in a prepared layout: provenance files in the root, raw HTML and diagrams in `archives/`, sections as folders. It has tables, draw.io and PlantUML diagrams, C4 views, text and pictures — the kinds of thing real designs contain. No real organisation's content.

Practise with it as the [onboarding workflow](../../docs/sdem-onboarding-workflow.md) shows: copy it with `mkdir -p work/imports && cp -r examples/designs/confluence-folder-export work/imports/payarch`, then `sdem transform inspect` / `run`. The automatic tests use it too, so do not edit it here — work on your copy.
